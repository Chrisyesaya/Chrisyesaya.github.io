# chrisyesaya.github.io

Personal portfolio of **Christopher Yesaya Susanto** — Mobile Engineer (Flutter) & Full Stack Engineer.

Live: **https://chrisyesaya.github.io**

- React 18 + Vite
- Framer Motion for type reveals, scroll-linked text, cursor-follow previews, velocity marquee and magnetic buttons
- Lenis smooth scroll
- Custom WebGL "black silk" shader background
- Playable arcade (Snake, Breakout, Pong) on a canvas phone

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

Every push to `main` is built and deployed by `.github/workflows/deploy.yml`.
